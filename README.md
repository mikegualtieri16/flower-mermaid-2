# Bloomtail 🌺🧜‍♀️

A tiny mobile-first browser game about a magical flower with a mermaid tail.

## Gameplay

- Drag anywhere on the screen to steer Bloomtail.
- Collect glowing sun drops to score points.
- Avoid jellyfish.
- You have 3 lives.
- The game gradually gets faster.
- Best score is saved locally in the browser.

## Run locally

No build tools are required.

Just open `index.html` in a browser.

For a better local test, use a tiny web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `game.js`
3. Commit the files.

## Publish with GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/root`.
5. Save.

GitHub will give you a public game URL.
